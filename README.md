# Contents Under Pressure

The safety warning label that should come printed on every human being: contents under pressure, prone to tears, triple sneezes and car singing.

## The text

WARNING: contents under pressure. May leak tears at weddings, sneeze three times in a row, and burst into song alone in the car.

## How to run

Python 3.13, standard library only, no network.

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
